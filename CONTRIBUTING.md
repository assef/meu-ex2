# Contribuindo

Obrigado pelo interesse! Antes de abrir algo, leia isto.

## Pull Requests: não, obrigado

Este é um projeto **pessoal**. Eu implemento **apenas** as funções que eu uso no
meu carro, do jeito que faz sentido pra mim. Por isso **não aceito Pull Requests** —
eles serão fechados sem merge, sem ressentimentos.

## Quer mais funções? Faça um fork

O código é aberto justamente pra isso. **Forke à vontade**, adapte pro seu carro,
adicione o que quiser. Não tenho como dar suporte a forks, mas fico feliz que o
código seja útil de base.

## Issues

- **Bug no que já existe**: pode abrir uma issue descrevendo o problema e como
  reproduzir. Vou olhar quando der, sem promessa de prazo.
- **Pedido de função nova**: provavelmente não vou implementar (veja acima) — mas
  a issue pode servir de referência pra quem for forkear.

## Segurança / garantia

Lembre: o projeto mexe em parâmetros do veículo. Teste no seu carro por sua conta
e risco. Nada é gravado em `/system`, então um reset de fábrica reverte tudo.
